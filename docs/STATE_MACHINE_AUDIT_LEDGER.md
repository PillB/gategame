## Test quality and mutation ledger

- **Good negative control:** `scripts/check-complexity.mjs` deliberately runs an over-complex function through project ESLint and asserts a real `complexity` ERROR; a simple function must not fail. If the ESLint rule were absent or muted, the test fails.
- **Behavioral counterfactual:** `scripts/browser-smoke.mjs` backgrounds a *running* page and expects a frozen clock + auto-pause announcement. Deleting visibility-change handling must fail the test. The same scenario while paused must not restart the game.
- **Independent conservation oracle:** `tests/full-round.test.mjs` compares stay/switch decisions to `2×cleared + turnedAway` in no-abandonment classic rounds, not against a copied internal constant.
- **Historical baseline:** `tests/full-round.test.mjs` locks scores; `scripts/tick-visual-audit.mjs` compares browser state to actual engine and screenshots at each 0.1 s tick.
- **Weak non-oracles:** file-exists assertions, checking `source.includes("feature")`, self-comparison without a perturbation, or a green screenshot-only test. These cannot close a user-behavior gate.
